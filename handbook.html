Boosts Handbook

Everything Boosts can do, and every data-boost-* attribute you can use in your own markup.

Getting started

Open the panel on any page by clicking the toolbar icon or pressing Alt+B. Drag the header to move it, drag any edge or corner to resize it, and use the expand button (or double-click the header) for a large editing size.

A boost is a bundle of HTML injections, CSS, a page script and zapped elements. Everything saves automatically. Your changes apply to the page as soon as you pause typing (about half a second), so the page doesn't redraw on every keystroke. Ctrl+S applies and saves right away. A boost on a page you haven't edited yet is a draft and isn't saved until you change something.

Turn on “Allow User Scripts”. On chrome://extensions, open Boosts' details and turn it on. Without it, scripts fall back to a <script> tag, which sites with a strict Content Security Policy block. HTML, CSS and zaps work either way.

Site, page & multiple boosts

Applies to controls where a boost runs:

  • Whole site: every page on the same host, e.g. mail.google.com. Subdomains are separate sites.
  • This page: only this host and path, e.g. /mail/u/0. The part after ? or # is ignored.

A site can have several boosts. Open the menu under the boost name to switch between them, create a new one, or delete the current one. The switch in the header turns the current boost on or off. All boosts lists every boost you have, with toggles, search, delete and JSON import/export.

Elements

Click Select element (or right-click anything → Boost this element) and pick an element on the page. While picking:

  • ↑ / ↓ move to the parent / first child, ← / → to the siblings.
  • Enter or a click chooses, Esc stops.

Then write HTML and choose where it goes relative to the target:

InsertWhere the HTML goes
BeforeRight before the element, as a sibling.
StartInside the element, before its first child.
EndInside the element, after its last child.
AfterRight after the element, as a sibling.
ReplaceThe element is hidden (display: none, not removed) and the HTML goes in its place.

The Target is a CSS selector, and the injection applies to every element it matches. The counter shows how many matches there are. All similar drops the trailing :nth-child() so one injection covers every sibling like the one you picked. If the page re-renders or a single-page app adds matching elements later, Boosts injects into them too.

<script> tags inside injected HTML don't run. Put code in the injection's script instead.

Format (or Shift+Alt+F) pretty-prints the editor's contents. Ctrl+Z undoes it.

Word wrap is off by default. The wrap button (or Alt+Z inside a field) turns it on or off for that field only, and each field remembers its setting. With wrap off, long lines scroll sideways and the line numbers stay put. The HTML and script fields grow with your code up to about 18 lines and then scroll. Drag the bar under a field to make it taller or shorter.

Element scripts

Each injection can carry a script. It runs in the page's own JavaScript context, so it can see the page's globals, once for every element the selector matches. Three variables are provided:

NameValue
elThe matched target element. Also available as this.
nodeThe first element your HTML inserted, the same as nodes[0]. Most injections are a single element, so this is usually the one you want.
nodesAn array of all the top-level elements your HTML inserted next to or inside this target.
 
// Collapse the target when the injected button is clicked
node.addEventListener("click", () => {
  el.hidden = !el.hidden;
});

Don't declare your own variable called el, node or nodes (for example const node = …). Those names are already taken, so the script fails with a syntax error.

The script is wrapped in an async function, so await works. Errors go to the page console, prefixed with [Boosts] and the boost name.

Strict sites (Gmail): no HTML strings in scripts

Gmail and other Google apps enforce Trusted Types. Scripts run inside the page, so the page blocks every API that turns a string into HTML. That includes innerHTML, outerHTML, insertAdjacentHTML, document.write and DOMParser.parseFromString, even for XML. The console shows “This document requires 'TrustedHTML' assignment”. Work around it like this:

  • Put markup in the injection's HTML field. Boosts inserts it from outside the page, so it isn't blocked.
  • Build elements with document.createElement, textContent, append and setAttribute.
  • Read values out of text responses with a regular expression instead of parsing them:
const text = await (await fetch("/mail/u/0/feed/atom")).text();
const unread = Number(text.match(/<fullcount>(\d+)<\/fullcount>/)?.[1] ?? 0);

When it runs: on page load, whenever a new matching element appears, and when you press Re-apply (Ctrl+Enter). Editing the HTML re-inserts it live but doesn't re-run the script, because it would run on every keystroke. Press Re-apply when you're ready.

CSS

Applied live, as soon as you pause typing. Your CSS is added as a separate stylesheet after all of the page's own stylesheets, so for equally specific selectors your rules win. The page's Content Security Policy can't block it, and it's in place before the first paint, so there's no flash on load.

Pick selector adds an empty rule for any element you click. Inline styles and high-specificity rules on the page may still need !important.

Style your own injected markup with the data-boost-node attribute, or give it your own classes.

Page scripts

The Script tab runs once per page load, after the DOM is ready, in the page's own JavaScript context. Run now (Ctrl+Enter) runs it immediately.

Single-page apps like Gmail change views without a page load, so the page script doesn't run again. Listen for navigation yourself if you need to:

navigation.addEventListener("navigatesuccess", () => {
  console.log("Now on", location.hash);
});

Zap

Click Zap elements and click anything you never want to see again. Keep clicking to zap more, and press Esc or Done zapping to stop. You can also right-click an element → Zap this element. Zapped elements are hidden with CSS, so they never flash on load. The eye button shows an element again.

Attributes

Boosts reads and writes a few data-boost-* attributes. The first group is for you to put in your injected HTML. The second is set by Boosts, and you can use it from CSS and scripts but shouldn't write it yourself.

You add

data-boost-linkon an <a>, or any element wrapping links, in injected HTML

Makes an injected link work even on sites that block clicks on links they didn't create. Gmail is the common case: you see the URL in the status bar on hover, but clicking does nothing.

With the attribute, Boosts lets the click go through the page first. If the page cancelled it, Boosts follows the link itself: in the same tab for a normal click, in a new tab for a middle-click, Ctrl/Cmd+click or target="_blank".

<a data-boost-link href="https://mail.google.com/mail/u/0/#search/label%3Aunread">Unread</a>

Put it on a wrapper to cover every link inside:

<nav data-boost-link>
  <a href="#inbox">Inbox</a>
  <a href="#search/label%3Aunread">Unread</a>
</nav>

Prefer code? This element script does the same for every link in the injection. It's less robust, because it only runs if the page doesn't also stop the click from reaching the link:

for (const a of nodes.flatMap((n) => [n, ...n.querySelectorAll("a[href]")])) {
  if (!a.matches("a[href]")) continue;
  a.addEventListener("click", (e) => {
    e.preventDefault();
    location.href = a.href;
  });
}

Leave both out if your own script handles the link's clicks. The panel shows a reminder under the HTML editor when your HTML has a link without the attribute.

Boosts adds

data-boost-nodeon every top-level element you inject

Marks markup that Boosts inserted. Selectors never match inside it, so an injection can't inject into itself. Use it to style your markup without touching the page's own elements:

[data-boost-node] {
  font: 500 13px system-ui;
}

The value is an internal token that changes every time the HTML is re-inserted. Match on the attribute's presence, not its value.

data-boost-elon each element an injection targets

Holds space-separated tokens for the injections attached to the element. Boosts uses it to hand the right element to your script as el. It's handy for spotting targets in DevTools. Don't edit or remove it.

New attributes will be documented here as they're added.

Recipes

Add a shortcut link to Gmail's sidebar

Pick a sidebar entry, set Insert to After, and use a link with data-boost-link:

<a data-boost-link class="my-unread" href="#search/label%3Aunread">Unread</a>

Then style it on the CSS tab:

.my-unread {
  display: block;
  padding: 4px 26px;
  color: inherit;
  text-decoration: none;
}

Copy an element from DevTools

Right-click an element in DevTools → Copy → Copy outerHTML, paste it into the HTML editor, and press Format. Copied markup often carries the site's own event attributes, like jsaction in Gmail. They do nothing on a copy, so delete them to keep things readable.

Replace text on the page

// Element script on the target
el.textContent = el.textContent.replace("Inbox", "📥 Inbox");

Troubleshooting

The panel won't open (red ✕ on the icon)
Chrome doesn't let any extension run on the New Tab page, chrome:// pages or the Chrome Web Store. Try a regular website.
An injected link does nothing when clicked
The site blocks clicks on links it didn't create. Add data-boost-link.
“Matches 0 elements”
The selector no longer matches, often because the site renamed generated class names. Pick the element again, or use ↑ to move to a more stable parent.
My script doesn't run
Turn on “Allow User Scripts” (see Getting started). Without it, sites with a strict security policy block every script, and Gmail reports “This document requires 'TrustedScript' assignment”. Then check the page console for [Boosts] errors. Element scripts don't re-run when you edit the HTML; press Re-apply.
“This document requires 'TrustedHTML' assignment”
Your script used innerHTML, DOMParser or a similar API on a strict site. See Strict sites.
My CSS doesn't apply
The page's rule is more specific, or the element has an inline style. Add !important, or use a more specific selector.
